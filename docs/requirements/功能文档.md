# 学习奖励应用 — 功能文档

## 1. 功能模块总览

```
study-reward-app
├── 认证（star-sso）
├── 任务模板与任务执行（star-reward）
├── 积分、流水、兑换、背包（star-reward）
└── 壳层：导航、主题、自定义样式（前端）
```

## 2. star-sso 接口能力（OpenAPI）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/sso/login` | 登录 |
| POST | `/api/sso/logout` | 登出 |
| GET | `/api/sso/user/info` | 当前用户信息 |
| POST | `/api/sso/validate` | 校验 Token（多服务场景） |
| POST | `/api/sso/register` | 注册 |

**前端封装**：`src/api/auth-api.ts`（`login`、`register`、`getCurrentUser`、`logout`、`hasToken`）。  
**配置**：`VITE_SSO_BASE_URL`，默认 `/api/sso`。

**对接缺口**：`logout` 仅清除 localStorage，**未**请求 `POST /api/sso/logout`。

## 5. 界面功能与 API 映射

### 5.1 登录页 `LoginPage`

- 登录、注册 → `login`、`register`
- 进入主应用依赖 Token；用户信息展示在 `UserMenu` → `getCurrentUser`

### 5.2 学习任务 `TaskManager`

- 模板列表/新建/编辑/删除 → `TaskTemplateAPI`
- 进行中列表、按实例恢复 → `TaskExecutionAPI.getTaskExecutions`、`getExecutionByNo`
- 开始/暂停/恢复/完成/取消 → `TaskExecutionAPI.startTask` 等（`clientTime` 秒级时间戳）
- 完成发奖后刷新积分 → `UserAPI.getPoints`（经 `onPointsChange`）

### 5.3 积分商城 `Shop`

- 商品列表 → `ProductAPI.getProducts`
- 兑换 → `UserAPI.exchange`

### 5.4 我的背包 `Inventory`

- 列表 → `UserAPI.getInventory`

### 5.5 积分记录 `PointRecords`

- 分页与类型 → `UserAPI.getPointRecords`

### 5.6 顶栏与用户菜单

- 积分 → `UserAPI.getPoints`
- 用户昵称/用户名 → `getCurrentUser`（SSO）
- 退出 → `logout`（本地）

### 5.7 样式与主题

- 主题、自定义样式 → 本地存储与 `StyleCustomizer`；**无**对应 Reward OpenAPI 中的用户偏好接口（若未来扩展需后端支持）。

## 6. 数据类型要点（前端）

- **完成任务响应**：`CompleteTaskResponse` 含 `reward`（积分奖励），用于提示或刷新余额。
- **兑换响应**：`ExchangeResponse` 含 `pointsSpent`、`remainingPoints` 等，用于结果展示。
- **任务模板请求体**：当前为 `name`、`description`（见 `CreateTaskTemplateRequest`），与示意图「分类/图标/自定义积分」等扩展字段需后端模型与前端表单同步扩展。

## 7. 环境变量（摘要）

| 变量 | 用途 |
